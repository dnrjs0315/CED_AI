# 갈래말래: 예산으로 그리는 여행 동선

> “여기 가려면 얼마?”가 아니라 **“이 돈으로 어디 갈 수 있지?”**

보유 예산과 여행 선호도로 **갈 수 있는 여행지를 먼저 추천**하고, **현지 이동비와 이동 동선**까지 고려해 실제로 실행할 수 있는 여행 일정을 자동으로 만드는 웹사이트입니다.

## 실행 방법

**`실행.bat`을 더블클릭하세요.** 로컬 서버(`server.py`)가 켜지고 브라우저에서 http://localhost:8000 이 자동으로 열립니다. 파이썬 3.8 이상만 있으면 되고, 따로 설치할 패키지는 없습니다.

```bash
python server.py            # 직접 실행할 때
```

`index.html`을 파일로 바로 열어도 동작하지만, 그렇게 열면 **지도가 흐린 간이 지도로 나오고**, 실시간 시간표 조회와 카카오맵도 쓸 수 없습니다.

> **지도에 "Access blocked"가 뜨던 문제**
> OpenStreetMap 무료 타일 서버는 앱 식별 정보 없이 들어온 요청에 지도 대신 차단 안내 이미지를 보냅니다. 그래서 이제는 `server.py`가 타일을 대신 받아 옵니다(`/tiles/…`). 받은 타일은 `.cache/tiles`에 14일간 저장되므로, 한 번 본 지역은 다음부터 바로 뜹니다.

## 연동 설정 (선택)

키가 없어도 모든 기능이 동작합니다. 키를 넣으면 아래와 같이 바뀝니다.

| 기능 | 키가 없을 때 | 키를 넣었을 때 | 설정 위치 |
|---|---|---|---|
| 동선 지도 | OpenStreetMap 지도 (server.py 경유) | **카카오맵** | `js/config.js` → `KAKAO_JS_KEY` |
| 기차·버스·항공 시간표 | 노선 거리로 만든 **예시 시간표** (실제 편이 아니라서 코레일·티머니GO와 시각·열차번호가 맞지 않음) | **실시간 시간표와 요금** (국토교통부 TAGO) — 코레일 열차번호, 티머니 출발 터미널·시각과 일치 | `server_config.json` → `DATA_GO_KR_KEY` |

### 1) 카카오맵 JavaScript 키
1. https://developers.kakao.com 에서 로그인 → **내 애플리케이션 → 애플리케이션 추가하기**
2. **앱 설정 → 플랫폼 → Web 플랫폼 등록** → 사이트 도메인에 `http://localhost:8000` 추가
3. **제품 설정 → 카카오맵 → 사용 설정을 ON**
4. **앱 키**의 *JavaScript 키*를 `js/config.js`에 넣기
   ```js
   window.APP_CONFIG = { KAKAO_JS_KEY: '발급받은_JavaScript_키' };
   ```

### 2) 공공데이터포털 인증키 (실시간 시간표·요금)
코레일·티머니GO·스카이스캐너는 개인 개발자에게 공개된 API가 없습니다. 대신 **국토교통부가 공공데이터포털로 제공하는 TAGO API**에서 같은 기차·고속/시외버스·국내선 **시간표와 요금**을 받아 옵니다.

1. https://www.data.go.kr 회원가입 후 아래 4개 API를 검색해서 각각 **활용신청** (보통 자동 승인)
   - `국토교통부_(TAGO)_열차정보`
   - `국토교통부_(TAGO)_고속버스정보`
   - `국토교통부_(TAGO)_시외버스정보`
   - `국토교통부_(TAGO)_국내항공운항정보`
2. 마이페이지에 나오는 **일반 인증키(Decoding)**를 `server_config.json`에 넣기
   ```json
   { "DATA_GO_KR_KEY": "발급받은_인증키" }
   ```
3. `실행.bat`을 다시 실행하면 교통편 화면에 **● 실시간 시간표**가 표시됩니다.

인증키는 서버에서만 사용하므로 브라우저에 노출되지 않습니다. 승인 직후 1~2시간 정도는 `인증키가 등록되지 않았어요` 오류가 날 수 있으며, 그동안은 예시 시간표가 자동으로 표시됩니다.

### 실시간 시간표와 예매 사이트 맞추기
- **기차**: 열차번호를 코레일과 같은 형식(`KTX 001`, `무궁화호 1201`)으로 보여 줍니다. 서울은 서울·용산·청량리, 부산은 부산·부전처럼 도시마다 열차가 서는 역을 모두 조회하므로, 용산에서 출발하는 호남·전라선 KTX나 청량리에서 출발하는 강릉·안동행 열차도 나옵니다. 편마다 출발역이 함께 표시됩니다.
- **버스**: 고속버스와 시외버스를 모두 조회하고, 편마다 출발 터미널(서울경부·센트럴시티·동서울 등)을 표시합니다.
- 요금 정보가 비어 있는 편도 빼지 않고 `약 OO원`(예상 요금)으로 보여 줍니다.
- 같은 노선·날짜의 조회 결과는 서버에서 10분간 재사용해 공공데이터포털 호출 한도를 아낍니다.

### 예매 연결
시간표에서 편을 고르면 해당 사이트로 바로 가는 버튼이 나옵니다. 예매 사이트에서 같은 열차번호(버스는 같은 터미널·출발 시각)의 편을 고르면 됩니다.
- 🚄 기차 → **코레일**(letskorail.com)
- 🚌 버스 → **고속버스 티머니**(kobus.co.kr), **시외버스 티머니**(txbus.t-money.co.kr). 같은 표를 티머니GO 앱에서도 살 수 있습니다.
- ✈️ 항공 → **스카이스캐너** (출발·도착 공항, 날짜, 인원이 미리 채워진 검색 결과로 이동)

| 2 | 출발지 | 16개 도시 (기차역·버스터미널 둘 다 있는 곳은 둘 다 표시), 왕복 교통 성향(저렴하게 / 빠르게) |

| 4 | 후보 생성 | 전체 비용을 계산해 예산을 넘거나 이동시간이 부족한 여행지 제외 |
| 5 | 취향 가지치기 | 자연/도심 → 관광/맛집 → 테마 → 유명/숨은 명소 순서로 후보 제거 |

| 9 | 카테고리 | 문화·역사, 자연, 먹거리, 쇼핑, 체험, 휴식·카페, 야경, 도심 핫플 |
| 10 | 필수 장소 | 꼭 가고 싶은 장소 선택 (검색 가능) |
| 11 | 일정 생성 | 조건을 확인한 뒤 자동 생성 |
| 12 | 최종 일정 | 비용 명세, 예산 비교, 지도 동선, 일자별 타임라인, 식당 3곳 중 선택, 길찾기 링크 |

## 핵심 로직 (`js/planner.js`)

### 💰 비용
- **왕복 교통비**: 고른 편의 실제 요금을 씁니다. 고르지 않았으면 거리 기반 예상치를 씁니다. 공항이 시내에서 멀면(12km 이상) 공항 리무진 구간의 요금과 시간을 따로 더합니다. 예: 제주→여수는 여수공항 → 여수엑스포역.
- **현지 교통비**: 이동 구간마다 도보·대중교통·택시 중 하나를 골라 계산합니다. ⚡ 알아서 최적화는 `요금 + 이동시간 × 시간가치 × 인원`이 가장 작은 수단을 고릅니다.
- **식비, 관광지 입장료, 카페 및 기타**를 더하고, 최종 화면에 **총 예산 / 예상 사용 금액 / 잔여 예산**을 보여 줍니다.

### ⏰ 교통편과 일정의 연동
- 첫날은 **가는 편 도착 시각 + 공항 연결 시간 + 여유(역 10분, 공항 20분)**부터 시작합니다.
- 마지막 날은 **오는 편 출발 시각 − 공항 연결 시간 − 여유(역 20분, 공항 50분)**까지만 일정을 짭니다.
- 교통편을 바꾸면 현지에서 쓸 수 있는 시간과 왕복 교통비가 바로 다시 계산됩니다.

### 🗺️ 동선 최적화
1. 취향·카테고리·인기도로 관광지를 고릅니다. 필수 장소는 항상 먼저 넣습니다.
2. **k-means**로 가까운 관광지끼리 일자별로 묶습니다.
3. 도착지 → 1일차 → 2일차 → … → 귀가 지점이 한 줄로 이어지도록 묶음의 일자 순서를 정합니다.
4. 하루 안의 방문 순서는 **최근접 이웃 + 2-opt**로 이동거리를 최소화합니다.
5. 결과 화면에 **인기순으로 나열했을 때보다 몇 km 줄었는지** 표시합니다.
6. 구간마다 **카카오맵·구글 지도 길찾기** 링크가 있고, 하루 전체 동선은 카카오맵 링크로 열 수 있습니다(경유지 5곳씩 나눔).

### 🍽️ 음식점
점심·저녁 시간이 되면 **동선 위** 식당 3곳을 후보로 보여 줍니다. 다른 곳을 고르면 이동 구간과 비용이 자동으로 다시 계산됩니다.

## 파일 구조

```
창공/
├── 실행.bat             # 더블클릭 실행 (server.py 실행 + 브라우저 열기)
├── server.py            # 정적 파일 서버 + TAGO 시간표 프록시 (표준 라이브러리만 사용)
├── server_config.json   # 공공데이터포털 인증키
├── index.html
├── css/style.css
└── js/
    ├── config.js        # 카카오맵 JavaScript 키
    ├── data.js          # 출발지 16곳, 여행지 12곳, 역·터미널·공항, 국내선 노선
    ├── planner.js       # 비용·필터링·가지치기·동선 최적화·교통편 반영
    ├── transport.js     # 시간표 조회(실시간/예시), 예매 링크
    └── app.js           # 단계별 화면, 상태 관리, 지도(카카오맵/OSM)
```

`server.py`는 한 번 조회한 역·터미널 코드를 `.cache/` 폴더에 30일간 저장합니다.

## 참고
- 관광지·식당 좌표와 가격은 **시연용 추정치**입니다. 실제 서비스에서는 한국관광공사 TourAPI나 카카오 로컬 API 같은 데이터로 바꾸면 됩니다.
- 예시 시간표는 실제 운행표가 아니어서 열차번호·편명 없이 `KTX (예시)`처럼 표시합니다. 같은 노선과 날짜에는 항상 같은 결과가 나옵니다. 정확한 시간과 요금은 인증키를 넣은 실시간 조회나 예매 사이트에서 확인하세요.
- 회의 결정에 따라 숙소 기능은 없습니다. 숙박비는 1단계에서 예산에서 따로 빼 둘 수 있습니다.
