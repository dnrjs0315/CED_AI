갈래말래 사이트(수정본) 작업 정리 — 2026-10-04
====================================================

1. 여행 기간에서 3박 4일 제거
----------------------------------------------------
- 이유: 3박 4일은 너무 길어서 최대 2박 3일까지만 운영하기로 함
- 이제 고를 수 있는 기간: 당일치기 / 1박 2일 / 2박 3일

변경한 파일
- js/app.js     : 기간 선택 목록(DAYS_OPT)에서 '3박 4일' 항목 삭제
- js/planner.js : 일자 순서 결정 주석 수정
                  ("최대 4일 → 24가지" → "최대 3일 → 6가지")

확인 필요
- 이 PC에 Node.js가 없어 자동 실행 검사는 하지 못함
- 브라우저에서 1단계(예산) 화면의 기간 버튼이 3개만 보이는지 확인할 것


2. 제주처럼 넓은 여행지의 동선 문제 (검토만, 아직 구현 안 함)
----------------------------------------------------
문제
- 주요 관광지를 고르고 1·2·3일차 일정을 만들면, 제주는 하루하루가
  섬의 서로 다른 끝(동부·서부·서귀포)으로 나뉘어 이동이 너무 많아짐

원인
- 관광지를 인기 점수 순으로만 고름
  → 성산일출봉(동쪽 끝)과 협재해수욕장(서쪽 끝, 약 70km 거리)이 함께 뽑힘
- 고른 장소를 날짜 수만큼 지역으로 나눔
  → 2박 3일이면 섬을 한 바퀴 도는 일정이 됨
- 둘째 날은 전날 마지막 장소에서 출발함
  → 1일차를 성산에서 끝내고 2일차가 서부면, 아침에 버스로 3~4시간 이동

해결 방안 후보
 ① 권역 선택 단계 추가 (추천)
    - 제주를 제주시·공항 / 동부(성산·구좌) / 서부(애월·한림) / 남부(서귀포·중문)로 나눔
    - 기간에 따라 고를 수 있는 권역 수를 제한
      당일치기 1곳, 1박 2일 1~2곳, 2박 3일 2~3곳 (하루 한 권역 원칙)
    - 선택한 권역의 관광지만 후보로 사용
    - 데이터에 권역 정보만 추가하면 되고 지금의 일자 나누기 로직을 그대로 씀
 ② 장소를 고를 때부터 거리 반영
    - 이미 고른 장소에서 멀리 떨어진 곳은 점수를 깎음
    - 사용자가 할 일은 없지만, 장소가 왜 빠졌는지 알기 어려움
 ③ 필수 장소를 고를 때 경고 표시
    - 예: "이 장소를 넣으면 2일차 이동이 1시간 30분 늘어나요"
    - ①이나 ②와 함께 쓰는 보조 기능
 ④ 하루 이동시간 상한
    - 하루 이동이 일정 시간(예: 2시간)을 넘으면 동선에서 가장 벗어난 장소부터 자동 제외

추천 조합: ① + ③
- 사용자가 "이번엔 동쪽만"처럼 직접 고를 수 있어 이해하기 쉬움
- 발표 때 "넓은 지역은 권역으로 나눠 이동 피로를 줄였다"고 설명하기 좋음
- 서울·부산 등 다른 여행지는 지금처럼 권역 선택 없이 진행

다음에 정할 것
- ①~④ 중 어떤 방식으로 구현할지
- ①로 간다면 제주 외에 권역 선택을 적용할 여행지(강원 등)가 있는지
